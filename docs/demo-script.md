# Demo script

**Runtime:** 2 minutes 45 seconds. Record the web app in its labelled sample-data preview. The side-by-side shot uses two existing pages.

| Time | On screen | Narration |
|---|---|---|
| 0:00–0:18 | Market page. Keep “Preview · sample data” visible, then show the index chart and trade ticket. | “This is Kadex’s sample-data preview. Kadex is a prototype for trading graded-card prices on Solana. Nothing has been deployed to devnet yet.” |
| 0:18–0:40 | Market ticket. Select Long, enter a size, and point to margin, estimated liquidation price, borrow cost, and capacity. | “A trader can inspect the cost and liquidation price before opening a long or short. The market refuses a position that exceeds its capacity.” |
| 0:40–1:00 | Select Hedge in the Market ticket. Show its inventory-value input and estimated cost. | “A dealer can size a short against the value of cards on the shelf. Hedge mode uses the same trade, framed around inventory.” |
| 1:00–1:20 | Vault page, then an existing card detail page under `/vault/[address]`. Show appraisal, fractions, and redemption condition. | “The vault is designed for whitelisted Collector Crypt cards. It mints a fixed number of fractions. Redeeming the card requires every fraction back.” |
| 1:20–1:43 | Pool page. Show total value, deposit choices, and the explanation of withdrawal into both assets. | “Liquidity providers supply USDC or fractions. They receive CLP shares and take the other side of trader PnL. A withdrawal returns both pool assets.” |
| 1:43–2:06 | Portfolio page, top row: **Your open PnL**, **Pool NAV** and **Pool owes traders** side by side. Keep all three labels readable. | “Trader PnL and pool NAV belong together. When traders win, the pool owes them more. Portfolio shows both values on one screen.” |
| 2:06–2:27 | Index Methodology page. Show the solvency and depth capacity figures and the binding limit. | “Risk is capped by pool solvency and pricing-pool depth. In the documented sizing example, depth permits $8,972, while solvency permits $233,333.” |
| 2:27–2:45 | Return to Market with the preview label visible. End on the trade ticket. | “The programs and local-validator tests are built. The card-backed basket and public devnet deployment remain work to do.” |
