# Naming

Candidates for replacing the working name SLAB. Brainstorm record, 7 Oct 2026.

Constraints: one word, no spaces, English or Japanese, no Portuguese. Reference
register: slab, eilo, kori, nora.

## How to read the "check" column

- **searched** — a web search for the name plus crypto/token/Solana/fintech
  terms was run and the result is noted. Summaries only; project pages were
  not opened.
- **none** — no search was run. Any note is from memory.

Nothing here was checked for domain, X handle, trademark, or a direct ticker
lookup on DexScreener or CoinGecko. "Nothing found" means nothing surfaced,
not that the name is free. Japanese meanings are from memory and should be
confirmed by a native speaker.

## Why rename

SLAB collides inside the same niche (searched):

- Slab / SlabDrop — tokenized Pokémon and One Piece cards on Solana, with a
  $SLAB token already issued
- Slab Cash — tokenized collectibles, described as built on Collector Crypt
- Slab Finance — lending against Pokémon cards
- SlabsOTC and Slabz in Solana dApp directories; Slab.com outside crypto

None is large, but the ticker is taken.
